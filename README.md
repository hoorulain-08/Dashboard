<h1 align="left">Administrator Monitoring Tool</h1>
<p1>This web application provides administrators with task management and analytical tools to monitor activity and derive insights based on key statistics. The dashboard’s main view presents a summary of essential metrics, including balance, customers, orders, earnings, complaints, in-stock items, returned orders, and out-of-stock items. </p1>
